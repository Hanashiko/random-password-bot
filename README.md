# 🔐 Random Password Bot

Цей Telegram-бот створює випадкові (random) паролі на запит користувача. Реалізований з використанням `aiogram` на Python.

---

## 📁 Структура Проєкту
```
.
├── create_bot.py # Ініціалізація та конфігурація бота
├── handlers/
│ └── general.py # Основна логіка обробки повідомлень
├── main.py # Точка входу для запуску бота
├── README.md # Документація
└── requirements.txt # Список залежностей
```

---

## ⚙️ Функціональність

- Генерація випадкових паролів
- Налаштування довжини пароля (за замовчуванням: 12 символів)
- Можливість включення/виключення:
  - Цифр
  - Великих літер
  - Малих літер
  - Спеціальних символів

---

## 🔧 Технології

- Python 3.x
- [aiogram](https://docs.aiogram.dev/) — асинхронна Telegram Bot API бібліотека
- `secrets`, `string` — для генерації паролів

---

## 🚀 Як Запустити

1. Клонуй репозиторій:
   ```bash
   git clone https://github.com/Hanashiko/random-password-bot.git
   cd random-password-bot
   ```
2. Встанови залежності:
   ```bash
    pip install -r requirements.txt
   ```
3. Додай свій Telegram Bot Token у create_bot.py:
   ```bash
    bot = Bot(token='ТВОЇЙ_ТОКЕН')
   ```
4. Запусти бота:
    ```bash
    python main.py
    ```

---

## 🧪 Приклад Користування

Користувач надсилає повідомлення:
```bash
/password
```
Бот відповідає:
```bash
G7@p9b!Q1r#
```

---

## 🔒 Безпека

Паролі генеруються з використанням модуля secrets, що забезпечує криптографічно безпечну генерацію випадкових символів.
